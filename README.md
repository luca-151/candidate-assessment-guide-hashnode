# Candidate Assessment Guide

**[Candidate Assessment Guide](https://candidateassessmentguide.com)** is an independent publication covering hiring assessments, one-way video interviews and admissions tests from the candidate's side: head-to-head comparisons, vendor explainers and industry data, with every fact checked against the vendors' own pages and a date on every article.

## How we compare

Every tool and vendor is scored on the same published rubric: formats covered, free tier, price and billing model, timing realism, feedback quality and employer coverage. No tool is ranked first by default, and no tool pays for placement. Corrections are made with a dated note, never silently.
